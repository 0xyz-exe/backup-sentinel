# Security Policy

## Reporting Security Issues
We take the security of Backup Sentinel very seriously. If you discover a vulnerability or security issue, please do not file a public GitHub issue.

Please report vulnerabilities privately by emailing `security@sentinel.local` or opening a private GitHub Security Advisory. Include:
- A description of the issue.
- Steps to reproduce.
- Proof of concept payload or script.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
